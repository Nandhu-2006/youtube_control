 YouTube Gesture Control

Control YouTube with hand gestures using Python + OpenCV + MediaPipe

Gestures:
- 5 fingers = Play/Pause
- 1 finger = Forward 10s
- 2 fingers = Backward 10s
- 3 fingers = Volume Up
- 4 fingers = Volume Down

Install: pip install mediapipe==0.10.21 opencv-python pyautogui
Run: python youtube_control.py
