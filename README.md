# YouTube Gesture Control ✋📺

Control YouTube videos with hand gestures using Python, OpenCV and MediaPipe. No mouse needed!

### Gestures
| Fingers | Action |
|---------|--------|
| 5 fingers | Play / Pause |
| 1 finger | Forward 10 sec |
| 2 fingers | Backward 10 sec |
| 3 fingers | Volume Up |
| 4 fingers | Volume Down |

### Tech Stack
- Python 3.10 / 3.11 / 3.12
- OpenCV
- MediaPipe 0.10.21
- PyAutoGUI

### Installation

```bash
# Clone repo
git clone https://github.com/Nandhu-2006/youtube_control.git

# Install packages
